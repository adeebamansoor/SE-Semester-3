# Singly Linked List in C++



## Programs

1. `three_nodes_traversal.cpp` — creates three nodes with values 10, 20, 30 and displays them.
2. `five_nodes_fixed_values.cpp` — creates five nodes with values 5, 10, 15, 20, 25 and counts them.
3. `five_nodes_user_input.cpp` — takes five values from the user, builds the list, displays it, counts nodes, and frees memory.

## Concepts Covered

- Node structure (`data` and `next`)
- `head` and `tail` pointers
- Dynamic memory allocation using `new`
- Connecting and traversing nodes
- Counting nodes
- Releasing memory using `delete`




## Sample Input

```text
10
20
30
40
50
```

## Expected Output

```text
Enter value 1: 10
Enter value 2: 20
Enter value 3: 30
Enter value 4: 40
Enter value 5: 50
Linked List: 10 -> 20 -> 30 -> 40 -> 50 -> NULL
Total nodes: 5
```

## Time Complexity

- Traversal: `O(n)` — each node is visited once.
- Access through a known pointer: `O(1)`.
